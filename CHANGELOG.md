# Changelog

## 0.1.0

First public release.

- Side panel with three tabs (Overview, Tasks, Session) and a status bar item.
- Reads Claude Code's own session transcripts: no hooks to install.
- Current activity (thinking, running a tool, idle), turn timer, context usage, token totals, tool counts, subagents.
- Task progress from Claude Code's built-in to-do list, plus your own progress files.
- Quota (5h / weekly) from a local file or, if you opt in, Anthropic's usage endpoint. Optional statusline helper.
- English and Simplified Chinese UI. Light, dark and narrow layouts.
